# Pre-window analysis registration: CANVAS archival audio

Registered before the September 12–19, 2026 observation window. This document fixes analysis choices, not results, statistical power, scientific priority or publication readiness. The separately frozen prospective selection v1 (`c5ed56104a2c2b558449d0ed907470dfb89e913d6913b72c560d8f63bb556e82`) and its explicit pre-window dependence amendment govern selection. The original selection is never silently overwritten. Maximum500 observations within one fixed week is a pragmatic scope, not a power calculation or a minimum success target. A short or negative study remains reportable; dates and ranks will not be extended based on yield.

## Endpoint and comparison

Primary endpoint: mean net additional exact FCS-stripped strict AX.25 UI PDUs per recording for the frozen repaired **progressive** receiver relative to the union of the independently run Dire Wolf(-F0) and gr-satellites arms, on observations complete for all five receivers. For observation i, let A_i be progressive's set and B_i the external union. Report gains G_i=|A_i\B_i|, losses L_i=|B_i\A_i|, and mean(G_i-L_i), never just a favorable percentage. Also report both raw totals and the fraction of complete observations with any gain, any loss, either, or neither.

Secondary descriptive endpoints: innovation-v2 versus external union; innovation-v2 versus the fixed no-codec-v1; each receiver separately; exact native-receiver union as a postprocessing set union (not a separately implemented/timed decoder); total outer PDU bytes; globally distinct PDU bytes; recovery occurrence per observation. Every comparison reports added and missed sets. Observations, sliding windows, hypotheses and repeated frames are not interchangeable denominators. Distinct frames absent from one run are not necessarily absent from the public archive. No archive-new or transmitter-authenticated claim follows from CRC.

Native outputs require their received FCS, independent bitwise CRC verification, shared structural filtering, actual full-bank coverage and frozen input/configuration identity. External exports omit FCS; their integrity is decoder-attested under the pinned settings, not verified by appending a newly calculated checksum. No target-bit repair or known archived payload input is allowed. The innovation arm receives additional original-OGG codec side information; common PCM16 samples do not imply identical side information.

## Missingness and runtime

Always show the original selected count, acquisition availability/format failures, attempted counts, per-arm complete/incomplete/unsupported counts and all-five-complete count before recovery totals. A decoder error, timeout, missing artifact or unattempted observation is **missing**, not an empty frame set. Complete-case results may be biased by this selection. Report the observed lower-bound byte yield over the intended cohort only as observed processing yield; it is not an estimated reception sensitivity or an imputed comparison. No favorable complete-case result alone establishes noninferiority over the intended cohort.

Report wall/user/systemCPU costs and available peakRSS for every completed arm, plus failed/timed-out costs separately. Startup is included; acquisition/conversion are separate. Four observation workers and two native threads, a900s process safety bound and rotated arm order remain fixed. Concurrent wall timing is not isolated latency, equal compute, or a hard realtime guarantee. A full bank that cannot finish is incomplete even if it has already produced some frames.

## Dependence and uncertainty

The unchanged120min same-NORAD gap rule is primarily a conservative exclusion guard against prior waveform exposure. Connected components using that gap can transitively merge consecutive passages, so they are not measured orbital passes. For evaluation, predeclare three temporal-component summaries, all using the entire selected metadata cohort before restricting to complete cases: same-NORAD intervals connected at gaps0,1800 and7200 seconds. Primary conservative uncertainty uses7200; the0/1800s versions are sensitivity summaries, never substitutes selected because their intervals are narrower or significant. The runner's existing0s summary is labelled accordingly, not silently treated as the primary conservative result.

For each grouping, resample complete contributing components with replacement10,000 times using fixed xorshift64 seed `d4514bca7f922026` (the existing benchmark procedure). Aggregate paired gains/losses and divide by the resampled number of observations, preserving within-component dependence and cluster size. Report empirical2.5/97.5 percentiles only with at least10 contributing components. This threshold is an operational suppression rule, not a theorem that10 clusters suffice. Below it, report descriptive totals and unavailable intervals. Relative gain is undefined for a zero comparator denominator; if any bootstrap draw has zero denominator, suppress the relative interval and report the count of undefined draws.

Also report seven UTC-day strata and leave-one-day-out point estimates descriptively. Seven days are not enough to assert robust day-cluster asymptotics, and one spacecraft/week cannot establish cross-mission generality. Cluster dependence assumptions remain unverified. The caution about few and potentially dependent clusters is consistent with [Cameron and Miller(2015)](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf); this is not an application of their regression standard-error estimator. No p-values, multiplicity-adjusted discovery claim or publication gate is inferred from these descriptive bootstrap intervals.

## Freeze and reporting

The receiver/configuration, runner, comparators, acquisition selector, analysis source/executable and this registration must be hash-bound before the declared pre-window deadline. During evaluation, no development on included or nearby recordings and no parameter tuning. Required engineering corrections get a new version and explicit deviation record; observed results cannot be silently rerun under a changed method and called the same confirmatory study. Predeclared controls, failed controls, unavailable data and zero incremental codec-pool benefits are included in reporting. Public release, named-author review and journal submission remain separate actions.
