# Outcome-independent innovations benchmark selection v2

This policy is recorded before fetching new audio or running any decoder on this cohort. It is an internal timestamped freeze, not an external preregistration.

Target 500 observations from SatNOGS Network, CANVAS NORAD 68635, transmitter `GCmN6RULea8dAT7Qoat8z2`, GMSK 9600 baud, known AX.25/G3RUH component profile. This is not a general-modulation benchmark.

Primary interval is 2026-08-11T00:00:00Z through 2026-09-10T00:00:00Z (exclusive upper start bound; observation must have ended by September 10). If fewer than 500 fresh eligible metadata records exist, extend backward deterministically to 2026-07-12, and then to 2026-06-12, retaining every eligible record from later tiers before adding earlier tiers. No other extension is allowed in this version. Fetch the complete primary interval first; fetch each earlier disjoint interval only if needed. Tier selection uses metadata only.

Eligibility uses mission/transmitter/rate/mode, valid completed dates, and an allowlisted public `.ogg` payload URL. It does not use status, waterfall status, demoddata, frame count, station rating, or signal appearance. API rows are retained for provenance; payload objects and reference frame URLs are not fetched. Audio is accepted for evaluation only after a container-level ffprobe confirms original mono Vorbis at 48 kHz, finite duration 1–1800 s. An unsupported or unavailable selected observation is retained as unavailable, never counted as zero decoded frames or replaced by another observation.

Within each interval tier, group by UTC start date and station ID. Rank rows within each group by SHA256(`innovation-benchmark-v2:ID`), then numeric ID. Rank groups by SHA256(`innovation-benchmark-v2-group:DATE:STATION`) then date/station. Select round-robin across groups until the tier is exhausted or total reaches 500. This disperses the sample over dates and stations without inspecting outcomes. Retain group/pass covariates for clustered analysis; observation count is not the number of independent satellite passes.

Before API acquisition, conservatively exclude IDs found in existing in-scope research artifact paths or selected aggregate experiment manifests/cohorts. ID extraction reads metadata identifiers only and skips payload/frame fields. Keep the exact exclusion inventory and all scan limitations. This is locally detectable waveform exposure, not proof no collaborator ever saw a recording. The old 20-observation development set and known pilot IDs are excluded explicitly.

Freeze selection-plan.json, exposure inventory, complete metadata pages and cohort.json before downloading any waveform. Freeze receiver executable and parameters separately before decoding. Evaluate every selected row; keep acquisition and decoder errors separate from valid zero-frame results.

Transport: GET only, fixed HTTPS host allowlist, manual validated redirects, at most four concurrent downloads, at least 250 ms between request starts. Three bounded tries per HTTP hop; honor Retry-After globally per host without shortening its deadline. Metadata at most 200 pages per interval (600 total), 4 MiB/page. Audio at most 64 MiB per selected observation across attempts, and 12 GiB total transfer allocation for all selected observations. Require at least 25 GiB free plus 1 GiB in-flight reserve before each transfer. DNS uses a recorded scoped public resolver answer, preserving original URL, TLS hostname and system resolver configuration. Partial bodies and HTTP receipts are retained; no global deletion and no submission to SatNOGS.

Acquisition schema: `cohort.json` has `observations` in frozen evaluation order, including original IDs, start/end, station, transmitter and payload metadata. Files are `obs-ID/capture.ogg`; `downloaded.json` binds original bytes by SHA256 and reports audio metadata. Per-observation download records record success, failure or deferred/unavailable. These are not decoder outcomes.
