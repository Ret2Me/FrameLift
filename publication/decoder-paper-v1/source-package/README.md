# Telemetry Yield — preliminary manuscript source

English IEEE Access-format research draft; not submitted or peer reviewed.
The author information is deliberately incomplete. The result is a fixed
189/266 observation snapshot from 2026-09-12 22:52:19 UTC, not a final trial.

This package contains the manuscript, bibliography, frozen aggregate results,
and the original official IEEE Access template distribution (2026-05-13).
It does **not** contain the decoder, raw radio recordings, private local
benchmark paths, or a complete raw-artifact reproducibility bundle.

Build with `make`; verify layout/citations with `make verify`.
Dependencies: make, unzip, Node, and TeX Live latex-base, latex-recommended,
latex-extra, fonts-recommended and publishers collections.

Two visually inspected empty title-box warnings from the official class are
explicitly tolerated; all other overflows and unresolved references fail.
The full local study package has additional per-observation evidence checks.

The official template and its included sample files retain their original
attribution and distribution terms. No new licensing grant is made here.
Template source: https://ieeeaccess.ieee.org/authors/preparing-your-article/
